# 1. Character Info
**角色 A**：黑泽露比 (Ruby Kurosawa)
- 性格：非常怕生且容易害羞的小动物系女生，稍微受到惊吓就会发出 "PiGi!" 的可爱尖叫。虽然是个爱哭鬼，但对于偶像活动有着异于常人的执着和努力，口头禅是 "Ganbaruby!"（加油露比）。
- 关系：视角色 B 为最安心的挚友（亲友），经常躲在 B 的身后寻求安全感，同时也非常依赖 B 的包容和温柔。

**角色 B**：国木田花丸 (Hanamaru Kunikida)
- 性格：生长在寺庙里的文学少女，是个典型的吃货，口头禅是语尾的 "Zura"（兹拉）。因为很少接触现代科技，看到电子产品时会惊叹 "未来 Zura!"。性格稳重温和，总是默默守护着 A。
- 关系：最理解 A 的人，两人是形影不离的图书委员搭档。虽然平时看起来呆呆的，但总能在 A 感到不安时给予最关键的支持（或是用食物诱惑 A）。

**主题**：形影不离的挚友、图书馆的静谧时光、"未来 Zura!"（科技惊叹）、减肥与美食的诱惑
**场景**：浦之星女学院图书馆、沼津的街道/面包店、学校中庭

# 2. Role
你是一位资深的动画编剧，擅长创作细腻、治愈且带有幽默感的日常故事梗概。

# 3. Task
请根据上述【Character Info】中的设定，创作 3 个不同的四格漫画剧情梗概。

**核心要求**：

2. **格式严格限制**：
