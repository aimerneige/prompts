# 1. Character Info
**角色 A**：樱内梨子 (Riko Sakurauchi)
- 性格：看起来成熟稳重、彬彬有礼的钢琴才女，但其实内心戏丰富，容易害羞抓狂（特别是在涉及同人本喜好或遇到狗的时候）。
- 关系：Aqours 的作曲担当，经常被角色 B 拉去试穿新衣服或尝试新料理，虽然嘴上抱怨但其实很享受两人的时光。

**角色 B**：渡边曜 (You Watanabe)
- 性格：元气满满的全能少女，擅长烹饪和制作服装，口头禅是 "Yousoro!"，行动力超强。
- 关系：非常欣赏角色 A 的艺术气质，喜欢捉弄容易害羞的 A，视其为重要的队友和伙伴。

**主题**：互补性格、制服试穿、料理分享、偶遇小狗
**场景**：钢琴室、曜的房间、沼津海边或学校走廊

你是一位资深的动画编剧，擅长创作细腻、治愈且带有幽默感的日常故事梗概。

# 3. Task

3. **内容要求**：突出两个角色之间的互动细节和性格反差（如 A 的慌乱/害羞与 B 的直率/元气）。
