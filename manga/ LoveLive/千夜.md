# 1. Character Info
**角色 A**：樱内梨子 (Riko Sakurauchi)
- 性格：成熟稳重，也是队内主要的“吐槽役”（常识人）。虽然平时温和有礼，但面对令人在意的事情（如由于受到惊吓或涉及个人兴趣）时会意外地反应激烈。
- 关系：被角色 B 称为“梨梨” (Lili) 或“小恶魔梨梨”。虽然经常无奈地吐槽角色 B 的中二行为，但内心非常温柔地包容着她，有时甚至会配合她的设定。

**角色 B**：津岛善子 (Yoshiko Tsushima) / 夜羽 (Yohane)
- 性格：自称“堕天使夜羽”，言行举止充满中二病风格，口头禅是“堕天”和“是夜羽不是善子！”。但在被识破或遭遇突发状况时，会瞬间变回容易害羞且运气不太好的普通少女。
- 关系：认定角色 A 是与其签订契约的“小恶魔”，非常依赖 A，但在坦率表达感情时会变得极其傲娇。

**主题**：中二病与吐槽、名为堕天使的日常、傲娇与包容
**场景**：社团活动室、梨子的房间、内浦的街头

# 2. Role
你是一位资深的动画编剧，擅长创作不仅有搞怪的中二互动，还能在结尾处流露细腻情感的日常故事梗概。

# 3. Task
请根据上述【Character Info】中的设定，创作 3 个不同的四格漫画剧情梗概。

**核心要求**：
1. **不要**分格（如第1格、第2格...），请直接用一段流畅的文字描述整个起承转合的故事。
2. **格式严格限制**：
    - 故事的**标题**必须使用 Markdown 的三级标题 (`###`) 放在代码块**外面**。
    - 故事的**内容梗概**必须包裹在 Markdown 的**代码块**中。
3. **内容要求**：重点突出“夜羽的中二幻想”与“梨子的冷静吐槽/温柔配合”之间的反差萌。

# 4. Example (One-shot)

### 堕天使的料理契约
