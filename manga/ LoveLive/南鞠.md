# 1. Character Info
**角色 A**：松浦果南 (Kanan Matsuura)
- 性格：拥有一身健康肤色的潜水员，性格爽朗成熟，是团队里的大姐姐。体力极好，行事干练，但在面对角色 B 突如其来的亲密举动时，偶尔会流露出无奈或害羞的一面。
- 关系：Aqours 的舞蹈编排担当，和角色 B 是青梅竹马，两人之间有着深厚的羁绊（和两年的空白期），经常被 B 捉弄或要求拥抱（Hagu）。

**角色 B**：小原鞠莉 (Mari Ohara)
- 性格：拥有金发碧眼的混血大小姐，性格自由奔放，口头禅是 "Shiny!"，说话喜欢夹杂英语。虽然看起来行事夸张、总是开玩笑，但其实内心非常敏锐且珍视伙伴。
- 关系：尽管是酒店经营者家族的千金，但在 A 面前完全没有架子，最喜欢通过肢体接触（如飞扑拥抱）来向 A 撒娇，视 A 为世界上最特别的存在。

**主题**：青梅竹马的羁绊、突如其来的拥抱 (Hagu)、体力特训与偷懒、"Shiny!"
**场景**：淡岛海边（潜水店）、学校天台、鞠莉的豪华酒店房间或淡岛海洋公园

# 2. Role
你是一位资深的动画编剧，擅长创作细腻、治愈且带有幽默感的日常故事梗概。

# 3. Task
请根据上述【Character Info】中的设定，创作 3 个不同的四格漫画剧情梗概。

**核心要求**：
1. **不要**分格（如第1格、第2格...），请直接用一段流畅的文字描述整个起承转合的故事。
2. **格式严格限制**：
    - 故事的**标题**必须使用 Markdown 的三级标题 (`###`) 放在代码块**外面**。
    - 故事的**内容梗概**必须包裹在 Markdown 的**代码块**中。
3. **内容要求**：突出两个角色之间的互动细节和性格反差（如 A 的成熟/干练与 B 的奔放/撒娇），特别是体现她们之间那种不用言语的默契。

